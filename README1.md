# Snake Game

This is a simple snake game made using Python and Pygame while learning game development basics.

The player controls the snake using arrow keys and tries to eat the food without hitting the walls or itself.

## Features
- Snake movement
- Food spawning
- Snake growth
- Basic collision detection

## Technologies Used
- Python
- Pygame

## How to Run

Install pygame:

```bash
pip install pygame
```

Run the file:

```bash
python snake_game.py
```

## Controls
Use arrow keys to move the snake.

## About
This project was created for practice and to improve Python programming skills.
